# Обработка моделей

Скрипты, которыми тяжёлые сканы приводились к весу для сайта. Запуск Blender без окна:

```
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup --python tools/models/<скрипт>.py -- <вход> <выход> <параметры>
```

- `decimate.py вход выход доля` — одна сетка, упрощённая до доли треугольников; текстуры — JPEG.
- `shrink.py вход выход сторона` — сетка как есть, текстуры уменьшены до стороны (например, 2048).
- `bake.py вход выход треугольники сторона` — тяжёлый скан (в том числе с цветом в вершинах и без текстур) → лёгкая сетка с запечёнными текстурами цвета и рельефа. Перед упрощением поверхность склеивается по расстоянию и остаётся главный кусок: у сканов оперения тысячи хлопьев, без этого сетка не упрощается.
- `largest.py вход выход доля` — убрать мелкий мусор скана (куски меньше доли от самого большого).
- `cast.py вход.gltf выход.glb [--height 1.78] [--tris 22000]` — скан гипсовой детали → отливка для зала (`assets/models/stucco`): сварить куски, убрать обломки, выровнять спину в плоскость стены, масштаб в метры по высоте, упростить, затенение складок по полной сетке в `COLOR_0`; остальные параметры — в начале скрипта.
- `basket.py вход.glb выход.glb высота_м сторона` — корзина для бумаг (`assets/models/bin`): одна сетка, высота в метрах, дно на y = 0, середина дна в начале координат, текстуры до стороны, JPEG. Плетёная (Dudzy) — высота 0.36, витая (eeelabvisual) — 0.3; оригиналы — `originals/bin`.
- `preview.py вход.glb папка` — два снимка 800 px (`front.jpg` спереди и `three-quarter.jpg` в три четверти) в Blender (Eevee, без окна): серая стена за задней плоскостью, два источника света. Подходит для настенных вещей; камеры и цель правятся в конце скрипта. Третий параметр `fit` (или `fit-flat` — без затенения) — для высоких вещей вроде пилястры: кадр по габаритам, белая глина.
- `knocker.py вход.glb выход.glb [--tris 14000] [--head 0.22] [--tex 1024]` — скан дверного молотка (лев с кольцом, Musei Vaticani, Objaverse) → лёгкая вещь для двери (`assets/models/door/lion-knocker.glb`): плоскость двери — в z = 0, лицо к +z, голова прямо, кольцо внизу; лоскуты двери отрезаны по глубине и цвету текстуры, метры по высоте головы (`--head`), цвет и нормали запечены с полной сетки в 1024 px JPEG, один материал (металл 0.6, шероховатость 0.45). Параметры плоскости и габариты головы подобраны под этот один скан (в начале скрипта).
- `lamp_lod.py вход.glb mid.glb far.glb [--glass-skip i,j]` — банкирская лампа (`assets/models/bankers-lamp.glb`) → две лёгкие версии для дальних столов: `mid` (body, glass, chain; около 11,3 тыс. треугольников) и `far` (body, glass; около 1,2 тыс.). Узлы режутся на части по правилам в начале скрипта (цепочка — всё, что висит в отвесе её бусин: звенья, бусины, кисточка; стекло — высоко и широко: абажур и его латунная дужка; дужку отдаёт в body `--glass-skip 1` — так и собраны копии в проекте, как в `desk.js`), каждая деталь упрощается отдельно; вершины остаются в мировых координатах оригинала, UV и нормали — с него же, материалов нет (текстуры берутся из оригинала). `--glass-skip` отдаёт найденное «стекло» (по порядку в списке, с нуля) в body.
- `tooled_cover.py -- крышка.jpg разворот.jpg assets/textures` — папка для листов из двух музейных снимков (папка Георга Хульбе 1902 года, Метрополитен-музей 2000.421.1, CC0; оригиналы — `https://images.metmuseum.org/CRDImages/es/original/SF2000_421_1_img1.jpg` и `…_img2.jpg`): вещь отделяется от фона, у корешка срезается полоска под пропорцию нашей крышки, фон в скруглённых углах закрывается кожей по соседству; рельеф тиснения — карта наклонов из яркости снимка; изнанка — левая половина разворота и чистый кусок кожи для зеркальных повторов. Blender нужен только ради numpy и чтения-записи картинок; числа снимка берутся как есть (`Non-Color`), иначе картинка выходит темнее.

Правка описания материала без Blender (`python3 -I скрипт.py вход.glb выход.glb`):

- `mr.py` — материал «блеск — зеркальность» (KHR_materials_pbrSpecularGlossiness) → обычный матовый с той же текстурой;
- `opaque.py` — убрать прозрачность и собственное свечение.

Правка текстур в браузере (открыть страницу с сервера проекта, выбрать исходные файлы):

- `chair_retouch.html` — Green Chair 01, текстуры 1k: закрасить следы подлокотников (стойка на боку и верху подушки сиденья, пустое место на стойках спинки) в цвете, рельефе и шероховатости разом; что и откуда берётся — таблица `OPS` в начале. Результат — `assets/models/chair/textures/*_armless.jpg`; сами подлокотники снимает `withoutArms` в `src/room.js`.

Подставка для книги (`assets/models/bookstand`, Wood Stand Book Reader, Francesco Coldesina, CC BY 4.0; оригинал — в `originals/stand`, вне git). Исходные оси модели: Z вверх, мм; в glb — метры, Y вверх:

- `stand_parts.py вход.glb` — осмотр: после склейки по расстоянию в сетке 7 тел (основание вместе с рамкой — одно тело, они сходятся нижним ребром), габариты каждого.
- `stand_kin.py` (обычный Python, `python3 -I`) — кинематика: ось нижних шарниров рамки, штифт распорки, шаг выемок зубчатой планки, угол рамки и поворот распорки на каждую из 6 ступеней, проверка врезания остриём распорки в планку. Числа записываются в узел `bookstand` (`extras`).
- `stand_build.py вход.glb папка [--work папка]` — режет сетку по её же швам (535 кусков -> `base`, `rack`, `frame`, `strut`; куски шарниров — тому, кто на них вращается), ставит точки вращения (`frame` — на оси шарниров, `strut` вложен во `frame`), перекрашивает текстуру (шоколад и палисандр: только уровни и цвет, зерно остаётся; латунь шарниров — по маске металла карты шероховатости), сглаживает шероховатость, пишет два glb без meshopt (метры, цвет JPEG 1024, нормали PNG 1024, шероховатость PNG 512). Нужен Blender ради numpy и записи картинок.
- `stand_render.py подставка.glb кадр.jpg ступень вид [--nobook] [--samples N] [--res WxH]` — снимки Cycles: тёмный стол, тёплая лампа слева сверху, книга 17 x 24 x 3 см на полочке. Вид: `side`, `tq`, `close`, `close34`, `hinge`, `hinge2`. Позу ставят сами узлы glb, как будет делать код зала.

- `lounge/palm_build.py вход_пальма.glb вход_жардиньерка.glb выход.glb [--tris 5000] [--twin 0.5] [--palm-k 0.97] [--lean]` — пальма (AllQuad) в жардиньерке (matousekfoto) для клубного угла: жардиньерка — три куска скана → одна лёгкая сетка с запечёнными цветом и нормалями (JPEG 1024), 0,5 м; пальма — без горшка, посажена на землю внутри (`--twin` — вторая, меньшая, копия для густоты; `--lean` — без карт рельефа и шероховатости листьев). Дальше `lounge/post.py` (альфа-отсечение листьев, металличность 0, множитель цвета); снимки — `lounge/preview_palm.py вход.glb папка` (спереди, в три четверти, жардиньерка крупно). Подробности — `assets/models/lounge/notes.md`.
