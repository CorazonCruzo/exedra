# Фильмотека проектора

Данные и медиа для немого кино в проекторе. Собрано 2026-11-22; план — `docs/cinema/2026-11-22-silent-films-handoff.md`.

## Что здесь лежит

| Файл | Что это |
|---|---|
| `catalog.json` | Витрина: 106 проверенных фильмов, по разделам |
| `commons-index.json` | Весь архив Commons: 2810 записей в компактном виде (≈190 КБ, ≈58 КБ в gzip) |

Собирается скриптами `tools/cinema/` (Node 22, без зависимостей):
`build-catalog.mjs` → `catalog.json`, `build-commons-index.mjs` → `commons-index.json`, общий клиент — `commons-api.mjs`.

## Витрина (`catalog.json`)

```
{ generatedAt, source, count, groups: [id раздела, ...в порядке показа], films: [...] }
```

Поля записи: `id`, `lang`, `group` (id раздела: `it`, `ru`, `en`, `fr`, `de`, `es`, `ja`, `pathe`, `colour`, `nordic`, `br`, `in`), `year`, `durationSec`; тексты (`title`, `director`, `note`, названия разделов и русские подписи автора) вынесены в переводы `i18n/<язык>.json` (см. ниже); `stream` — прямая ссылка на WebM для `<video crossOrigin>`; `streamKind` (`original` или `480p.vp9.webm`, `240p.vp9.webm`); `streamMb` — вес потока, МБ, `streamMbEstimated` — `true`, если вес оценён как битрейт транскода × длительность (API не отдаёт размер транскода), `false` — это точный размер оригинала; `streamSize` — «ширина×высота» потока; `license` (LicenseShortName), `attribution` (Artist, простой текст до 120 знаков), `commonsFile`, `commonsPage`; по необходимости `onboardingCandidate`, `modernAudio`, `heavy`.

Выбор потока: оригинал `.webm`, если он ≤ 60 МБ; иначе (и для любого `.ogv`/`.ogg`) — `480p.vp9.webm`, а если его нет — самый большой транскод ≤ 480p. Если на Commons вообще нет лёгкого транскода, остаётся оригинал (`streamKind: original`).

- `modernAudio: true` — в описании файла сказано про добавленную/синхронизированную звуковую дорожку или музыку. Сейчас только `es-72` («Серый автомобиль», версия 1956 года с синхронизированной звуковой дорожкой).
- `heavy: true` — `streamMb` больше 100 (42 записи). Из них две ленты стоят оригиналами и **лёгкого транскода на Commons нет** (в стартовом списке они были подписаны как `1080p`/`720p.vp9.webm`, но ссылки вели на оригинал): `fr-48` «Путешествие на Луну» (цветная, 1,7 ГБ) и `sv-101` «Сага о Гуннаре Хеде» (1,0 ГБ). Их лучше показывать с предупреждением или не предлагать на слабом канале. Остальные — длинные ленты, где даже 240p/480p весят 100–200 МБ.
- Лицензии: 104 — общественное достояние, 1 — CC0 (`ru-17`), 1 — CC BY 3.0 (`es-74` «Амалия», автор — Museo del Cine Pablo Ducrós Hicken; его надо показывать при просмотре).
- Выпавших записей нет: все 106 файлов на месте.

## Переводы подборки (`i18n/<язык>.json`)

```
{ groups: { <id раздела>: название }, films: { <id>: { title, director, note, attribution? } } }
```

`filmlib.js` грузит файл языка зала и английский (`en.json`) — запасной для любого пропуска. Режиссёры — латиницей в английском. `attribution` — только там, где подпись автора в каталоге была бы по-русски (4 фильма). `ru.json` пишет `build-catalog.mjs` из стартового списка; `en.json` и остальные языки ведутся вручную (новый фильм — запись в каждый файл).

## Весь архив (`commons-index.json`)

Что обходится: `Category:Silent films videos` (2735 файлов, часть — картинки/не видео) и страновые и тематические категории (Pathé-Baby films, Trick films videos, Silent era dance videos, Silent films videos of trains, Laugh-O-Gram, Kino-Pravda, Kinonedelja, Newsreels, Eye Filmmuseum; `Silent films of …` для Италии, Франции, России, Германии, Дании, Швеции, Японии, Испании, Аргентины, Бразилии, Индии, Великобритании, США, Польши, Австрии; Segundo de Chomón). У кинокатегорий стран на Commons под каждым фильмом своя подкатегория, поэтому их подкатегории не обходятся; страна берётся ещё и из категорий самого файла («Videos of 1923 from France», «1915 films of the United States», «Pathé», «Edison» и т. п.). Файлы, которых нет в главной категории, берутся только с годом 1860–1935.

Исключено: всё из `Category:Videos from Polissons et galipettes` и любые файлы, в чьих категориях встречаются «erotic / nude / sexual / porn / lingerie / stag film …» (10 файлов); не-видео (картинки, GIF); файлы без WebM (ни оригинала `.webm`, ни `.vp9.webm`-транскода — 5); очевидные дубли (одинаковое имя без расширения, ` - yt`, `HD`/`4K`/`restored`, регистра и похожая длительность; остаётся WebM-оригинал, 29 штук).

Формат:

```
{
 "v": 1, "generatedAt": "...", "source": "...",
 "countries": [[код, подпись], ...],   // порядок = номер бита в маске стран
 "themes":    [[код, подпись], ...],   // порядок = номер бита в маске тем
 "licenses":  ["Public domain", "CC BY 3.0", ...],
 "fields":    ["name","year","durSec","sizeMb","stream","countries","themes","license"],
 "films": [
  ["Chocolat et Foottit (1890).webm", 1890, 239, 18, 0, 2, 0, 0],   // по одной записи на строку
  ...
 ]
}
```

Запись: `[0]` имя файла без `File:` (на Commons — `File:` + имя; пробелы, а не подчёркивания); `[1]` год (0 — неизвестен); `[2]` длительность, с; `[3]` размер оригинала, МБ (округлён вверх до 1); `[4]` подсказка потока: `0` — играть оригинал `.webm`, иначе число — высота предпочтительного VP9-транскода (`480` → `480p.vp9.webm`; при другом числе взять транскод такой высоты); `[5]` маска стран (бит i = `countries[i]`; 0 — страна не определена = «другое»); `[6]` маска тем; `[7]` индекс в `licenses`. Записи отсортированы по году, затем по имени. Годы: из `(YYYY)` в имени, затем из `DateTimeOriginal`, затем из категорий («Videos of 1903»).

Тема `newsreel` и страна `ru` у Kino-Pravda/Kinonedelja берутся из этих категорий; тема `eye` — из «Media from EYE Film Institute Netherlands», «Open Beelden» и `Category:Eye Filmmuseum`.

Состав (2810 фильмов; страны считаются по маске, поэтому могут пересекаться; «другое» — без определённой страны):

- по десятилетиям: до 1900 — 282; 1900-е — 523; 1910-е — 1002; 1920-е — 919; 1930-е — 47; 1940-е — 8; год неизвестен — 29;
- по странам: США 1539, Франция 513, Россия/СССР 154, Испания и Лат. Америка 115, Италия 73, Германия 57, Великобритания 31, Дания 28, Индия 14, Швеция 13, Япония 12, Бразилия 6, Нидерланды 2, Австрия 1, другое 383;
- по темам: Eye Filmmuseum 91, newsreel 51, dance 36, pathe-baby 29, trick 25, trains 13, laugh-o-gram 13;
- лицензии: «Public domain» 2788, CC BY 3.0 — 11, CC0 — 6, CC BY-SA 4.0 — 2, CC BY-SA 3.0 — 1, PDM-owner — 1, неизвестна — 1.

Фильтры длительности, десятилетия и поиск делаются на клиенте по этим полям.

## Лицензии и атрибуция

В индексе лицензия — только короткая метка; **автор и лицензия показываются при показе**: при выборе фильма из полного архива клиент делает один запрос к MediaWiki API (`action=query&prop=videoinfo&viprop=url|derivatives|extmetadata&titles=File:<имя>&origin=*`), берёт из `extmetadata` `LicenseShortName`, `Artist` (убрав HTML), `LicenseUrl` и показывает их рядом с названием вместе со ссылкой на страницу файла (`descriptionurl`). Это закрывает требование атрибуции для CC BY / CC BY-SA, а сами файлы не копируются в проект и не раздаются из него — зритель получает их с `upload.wikimedia.org`. Для ленты с `AttributionRequired: true` (поле `extmetadata`) показ автора обязателен. Общественное достояние обязывает лишь не искажать происхождение; метка «Public domain» берётся с самой страницы файла. Фильмы 1929–1935 лежат в основном архиве; в ряде стран (срок «70 лет после смерти автора») они могут быть ещё под охраной — решение о публичной лицензии принимали на Commons, но по осторожности ядро витрины держится до 1928 года.

## Стрекот проектора

`assets/sounds/projector-loop.ogg` — петля 10 с, моно, Opus 56 кбит/с (≈87 КБ), около −19,5 LUFS (пик −2 dBFS). Источник — запись настоящего проектора Super 8 Sankyo Sound 502 (семейные фильмы 1979 года), Work With Sounds / La Fonderie, CC BY 4.0: https://commons.wikimedia.org/wiki/File:WWS_Super8MovieProjector8211Projection.ogg (оригинал, 33,6 с, лежит вне git в `originals/cinema/`). Взят ровный отрезок 15,5–26,5 с; шов — перекрёстное затухание в 1 с (равная мощность), так что конец петли переходит в начало без щелчка; громкость по кругу ровная (±1 дБ). Opus добавляет до 6 мс хвоста — для `AudioBufferSourceNode` можно задать `loopEnd = 10`.

Другие подходящие записи с той же лицензией (на случай замены): `File:WWS CinemeccanicaprojectorVictoria9running.ogg` (35 мм кинотеатр, громче и «больше»), `File:Cinema projector OSSA VI.mp3` (35 мм, CC BY 4.0, Carlosjvives).

## Осторожно с Викисклада

`upload.wikimedia.org` отвечает 429 при частых запросах; API тоже (при сборке встретились ответы 429 с `Retry-After`, клиент ждёт и повторяет). Скрипты ходят только в API, по одному запросу раз в 1,5 с, с `maxlag=5` и понятным User-Agent; видеофайлы они не скачивают. Не предзагружать потоки пачками при открытии зала.
